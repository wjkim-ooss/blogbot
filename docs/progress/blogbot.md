# blogbot 진행 상황

마지막 정리: 2026-09-29. **2026-07-24 첫 대화부터** 다시 적었다 — 그 전 판은 9/20 이후만 담고 있었다.
근거는 이 채팅의 대화 기록 253개 발화와 커밋 173개(2026-07-24 ~ 09-28)다.

## 이게 무엇인가

에스테틱 원장이 쓸 네이버 블로그 초안을 만드는 웹 봇. 원장은 키워드 하나만 넣는다.
봇이 보관함의 상위글을 참고해 쓰고, 기계로 재서 기준에 못 미치면 다시 쓰게 한다.

- 사이트 https://blogbot-u7s9.onrender.com (Render 무료, main 에 push 하면 2~3분 뒤 자동 배포)
- 저장소 github.com/wjkim-ooss/blogbot · 로그인·회원 정보는 Supabase
- **쓰는 흐름**: 원장이 회원가입 → **우진이 승인** → 초안 작성. 등급은 둘이다.
  우진(관리자)은 무제한, 원장(level1)은 **월 15회**. 글이 한 줄도 안 나오면 횟수를 돌려준다.
- **초안은 쓴 사람 것이다.** 원장끼리 서로 못 본다. 관리자는 볼 수만 있고 고치거나 지우지 못한다
  (`permissions.mjs`). 원장이 넣은 샵 정보도 관리자는 읽기만 된다.
