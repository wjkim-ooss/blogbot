## A. 남은 일 — 새 버전 올리기 (3분)

1. 브라우저에서 → `https://github.com/wjkim-ooss/blogbot/upload/main`
2. Finder에서 **`우진 스레드/블로그봇-배포용`** 폴더 열기
3. 그 폴더 창 클릭 → **`Cmd + A`** (전부 선택)
4. 선택한 것들을 브라우저의 **"Drag files here"** 넓은 상자로 **끌어다 놓기**
5. 아래로 스크롤 → 초록색 **`Commit changes`** 클릭

> ⚠️ 폴더 자체가 아니라 **폴더 안의 내용물**을 끌어야 합니다.
> (`config.json`, `web`, `references`, `drafts` 등이 보여야 정상)

3분 뒤 자동 반영됩니다. 이번 버전에 담긴 것: 탭 바로가기 링크(`#drafts`), 오류 원인 정확히 표시, 한글 파일명 문제 방지.

**로그인은 그대로 유지됩니다.** (아무것도 안 하시면 로그인 방식이 기본값입니다.)

## D. AI 초안 생성 켜기 (선택, 유료)

지금은 꺼져 있고, 나머지 기능은 전부 무료로 작동합니다.

켜려면:
1. `https://console.anthropic.com` → **Billing** → 결제 수단 등록 + 충전 (최소 $5)
2. **API Keys** → **Create Key** → 키 복사
3. Render → Environment → `ANTHROPIC_API_KEY` 값에 붙여넣기 → Save

**비용 기준**: 초안 1건당 약 $0.1~0.2. $5로 25~50건.
더 아끼려면 저에게 "모델을 Sonnet으로 바꿔줘"라고 하시면 40% 절감됩니다.

### 초안은 누가 볼 수 있나

초안은 **계정별로 따로** 보관됩니다. 서버가 재시작돼도 사라지지 않습니다.

| 누가 | 자기 초안 | 다른 원장의 초안 |
|---|---|---|
| 원장 A | ✏️ 쓰기·수정·삭제 | ❌ **볼 수 없음** |
| 원장 B | ✏️ 쓰기·수정·삭제 | ❌ **볼 수 없음** |
| 관리자(우진) | ✏️ 쓰기·수정·삭제 | 👀 **열람 가능** (수정·삭제는 불가) |

**원장끼리는 서로의 글을 볼 수 없습니다.** 누가 어떤 글을 썼는지는 관리자만 확인할 수 있습니다.

#### 관리자가 원장 글을 보는 법
**초안 작성** 탭 → 왼쪽 위 **회원 선택 칸**에서 원장 이메일 선택 → 그 원장의 초안 목록이 뜹니다.
열람 중에는 주황색 안내줄이 뜨고 저장·삭제·AI 생성 버튼이 사라집니다. **본문 복사**는 되므로 피드백용으로 가져올 수 있습니다.
내 초안으로 돌아오려면 같은 칸에서 **📝 내 초안**을 고르세요.

같은 제목으로 써도 서로 덮어쓰지 않습니다. "📥 견본 초안 가져오기"를 누르면 견본이 **내 계정으로 복사**되므로, 내가 고쳐도 다른 원장에게는 영향이 없습니다.

> 권한 규칙은 [permissions.mjs](permissions.mjs) 한 곳에 모여 있고, `node --test` 로 검증합니다.
