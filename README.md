## A. 남은 일 — 새 버전 올리기 (3분)

1. 브라우저에서 → `https://github.com/wjkim-ooss/blogbot/upload/main`
2. Finder에서 **`우진 스레드/블로그봇-배포용`** 폴더 열기
3. 그 폴더 창 클릭 → **`Cmd + A`** (전부 선택)
4. 선택한 것들을 브라우저의 **"Drag files here"** 넓은 상자로 **끌어다 놓기**
5. 아래로 스크롤 → 초록색 **`Commit changes`** 클릭

> ⚠️ 폴더 자체가 아니라 **폴더 안의 내용물**을 끌어야 합니다.
> (`config.json`, `web`, `references`, `drafts` 등이 보여야 정상)

3분 뒤 자동 반영됩니다. 이번 버전에 담긴 것: 탭 바로가기 링크(`#drafts`), 오류 원인 정확히 표시, 한글 파일명 문제 방지.

**로그인은 그대로 유지됩니다.** (아무것도 안 하시면 로그인 방식이 기본값입니다.)

## C. 화면 사용법

| 탭 | 내용 |
|---|---|
| **레퍼런스 보관함** | 키워드별 상위노출 글. 제목 클릭 → 본문 펼침. 점수 = 글 품질 |
| **인사이트** | 평균 글자수·이미지 수, 제목에 숫자/이득단어 비율, 권장 스펙 |
| **초안 작성** | 편집기 + 실시간 검증(오른쪽 패널) + 저장 + 네이버용 복사 |

### 초안을 시작하는 세 가지 방법

| 버튼 | 설명 | AI 크레딧 |
|---|---|---|
| **✍️ 직접 쓰기** | 키워드를 넣고 누르면 뼈대(목표 글자수·사진 수·3대 기준)가 담긴 빈 초안이 생깁니다 | 안 씀 |
| **📋 AI 프롬프트 복사** | 레퍼런스까지 반영한 프롬프트를 복사합니다. **claude.ai에 붙여넣으면** 초안이 나옵니다 | **안 씀** |
| **🤖 AI 초안 생성** | 사이트가 직접 초안을 씁니다 | 씀 (월 한도 차감) |
| **📥 견본 초안 가져오기** | 논문 팩트체크 견본 등을 내 계정으로 복사합니다 | 안 씀 |

### 글자수를 직접 정하기

키워드 칸 옆 **글자수 (선택)** 에 숫자를 넣으면 그 길이에 맞춰 씁니다 (공백 제외, 300~20,000자).
**비워두면 그 키워드 상위글 평균**에 맞춥니다 — 보통은 비워두는 편이 상위노출에 유리합니다.

지정한 값은 세 곳에 모두 반영됩니다: 🤖 AI 초안 생성 · 📋 AI 프롬프트 복사 · ✍️ 직접 쓰기 뼈대.
검사 기준도 같이 바뀌므로, 3,000자로 지정하면 3,000자를 넘겨야 ✅가 뜹니다.

### 크레딧 없이 AI로 쓰는 법 (📋 AI 프롬프트 복사)

**Claude Max·Pro 구독은 API 크레딧을 포함하지 않습니다.** 우진님 구독으로 원장님들의 생성을 대신 돌릴 수는 없습니다.
대신 원장님이 **각자 자기 Claude 계정**(무료 계정도 가능)으로 쓰면 됩니다:

1. 초안 작성 탭에서 키워드 입력 → **📋 AI 프롬프트 복사**
2. https://claude.ai 에 붙여넣기 → 초안이 나옴
3. 사이트로 돌아와 **✍️ 직접 쓰기**로 빈 초안을 만들고, 받은 글을 붙여넣고 **저장**

복사되는 프롬프트에는 화자 설정, 논문 근거 규칙, 3대 기준, **상위노출 레퍼런스 40개의 제목·평균 글자수·이미지 수**가 전부 들어갑니다. 사이트가 직접 생성하는 것과 같은 지시문입니다.

> 자동 복사가 막힌 브라우저에서는 프롬프트가 편집기에 뜹니다. `Cmd+C`로 직접 복사하세요.

> 키워드는 정확히 안 맞아도 됩니다. `여드름`만 넣어도 `여드름 피부관리` 레퍼런스 40개를 참고합니다.
> 어느 레퍼런스를 참고하는지는 키워드 칸 아래 초록 글씨로 표시됩니다.

**📥 견본 초안 가져오기** — 초안 탭의 버튼. 논문 팩트체크 견본 등이 목록에 들어옵니다.

### 초안 목록에 뜨는 표시

각 초안 옆 `⚠️ 숫자`는 **고칠 점 개수**입니다 (마우스를 올리면 목록이 나옵니다). 그 아래 회색 줄은
키워드 횟수와 글자수예요. 열어보지 않고도 손봐야 할 글을 찾을 수 있습니다.

### 키워드 입력칸 아래 안내

생성 칸에 키워드를 치면 **레퍼런스가 있는지 바로** 알려줍니다.
`✅`면 상위글 평균에 맞춰 쓰고, `⚠️`면 기본 기준으로만 씁니다 — 이 경우 보관함에 먼저 크롤링하세요.

### ⚠️ 표시는 무슨 뜻인가

**고장이 아니라 검사 결과입니다.** 초안 목록의 ⚠️ 숫자는 **반드시 고쳐야 할 것의 개수**입니다.

| 표시 | 뜻 |
|---|---|
| ✏️ | **아직 작성 전** — 직접 쓰기로 만든 빈 뼈대입니다. 검사 안 합니다 |
| ✅ | 기준 통과 — 그대로 올려도 됩니다 |
| ⚠️ N | 고칠 점이 N개 있습니다. 편집기 오른쪽 맨 위에 무엇을 고칠지 나옵니다 |

**🤖 AI 초안 생성으로 만든 글은 대부분 ✅로 나옵니다.** 서버가 검증해서 미달이면 **최대 3번까지 다시 고쳐 쓴 뒤** 저장하기 때문입니다.

**사진 수·제목 숫자 같은 권장 사항은 ⚠️에 안 셉니다.** 주황색 "더 좋게 하려면"에 따로 나오고, 안 고쳐도 통과입니다.

> 💡 **검증용 키워드는 파일명에서 자동으로 뽑습니다.** 실제로 노리는 검색어와 다르면 **검증용 키워드** 칸에서 고치세요.
> 예: 견본 `화장품-성분-팩트체크`는 "화장품 성분 팩트체크"로 잡혀 0회가 나오지만, `화장품 성분`으로 고치면 바로 통과합니다.

### 키워드 검증이 세는 방식

- **논문 근거(PMID)는 "효능을 주장할 때만" 요구합니다.** `여드름 관리를 받으러 오셨습니다` 같은 평범한 서술은 통과하고, `여드름이 개선됩니다`·`콜라겐이 2배 증가` 처럼 **효과를 단정한 문장**이 있을 때만 근거를 요구합니다. 어느 문장이 걸렸는지 그대로 보여줍니다.
- **띄어쓰기는 무시합니다.** `여드름 피부관리`와 `여드름피부관리`는 같은 키워드로 처리됩니다 (레퍼런스 매칭도 동일).
- **판정은 키워드 '전체' 기준**입니다. 단어를 쪼개 세지 않으므로, 키워드는 통째로 문장에 들어가야 카운트됩니다.
  단어별 횟수는 그 아래 회색 참고값으로만 보여주고 합격·불합격을 가르지 않습니다.
- **3~7회를 벗어나면 표시됩니다.** 3회 미만은 🔴 부족, 7회 초과는 🟠 과다(네이버가 키워드 도배로 보고 감점).
- **목표 글자수는 1,300~1,500자**입니다. 통과선은 1,300자, 노리는 지점은 1,500자예요.
  상위글 평균(2,000자 이상)을 목표로 삼지 않는 이유는, 원장님이 매번 쓸 수 있는 분량이 아니면 실제로 안 쓰이기 때문입니다.
  더 길게/짧게 쓰고 싶으면 **글자수 (선택)** 칸에 직접 넣으세요.

### 제목 검증

제목은 상위노출에서 가장 무거운 자리라 따로 확인합니다.

- **키워드 포함** — 없으면 🔴. AI 생성 시에도 자동 보완 대상입니다.
- **숫자 포함** — 권장 사항일 뿐 감점은 아닙니다. 숫자가 든 제목이 클릭률이 높습니다.
- **길이** — 권장 25자 내외 (공백 제외).

### 사진 자리

통과 기준은 10곳으로 그대로입니다. 다만 상위글은 평균 30장이 넘어서, 레퍼런스가 있으면
**20곳 이상 권장**과 실제 평균을 함께 보여줍니다. 사진이 많을수록 유리합니다.

## D. AI 초안 생성 켜기

엔진이 **두 가지**입니다. 둘 중 하나만 켜면 됩니다.

### 🟢 무료 — 구글 Gemini (추천)

**돈이 전혀 안 듭니다. 카드 등록도 필요 없습니다.**

1. `https://aistudio.google.com/apikey` → 구글 계정 로그인 → **Create API key** → 키 복사
2. Render → Environment → **Add Environment Variable**
   - Key: `GEMINI_API_KEY`
   - Value: 복사한 키
3. **Save** → 2~3분 뒤 켜집니다

원장님들은 아무것도 설치하지 않고 사이트에서 바로 씁니다.

> ⚠️ **알아두실 것**: 무료 등급은 구글이 입력·출력을 자사 제품 개선에 쓸 수 있고, 사람이 열람할 수도 있습니다. 블로그 견본 원고라 문제될 게 없다고 보지만, 고객 개인정보 같은 건 넣지 마세요.
> 하루 사용량 한도가 있습니다(모델별로 다르며 AI Studio에서 확인). 초과하면 다음 날 다시 열립니다.

블로그봇이 그 키로 쓸 수 있는 모델을 직접 물어봐서 자동으로 고릅니다. 구글이 모델을 바꿔도 안 깨집니다.

**구글의 하루 한도는 모델마다 따로 셉니다.** 그래서 블로그봇은 쓸 수 있는 모델을 전부(보통 7개쯤)
순서대로 쥐고 있다가, 한 모델의 하루치가 끝나면 다음 모델로 넘어갑니다. 하루에 쓸 수 있는 글이
그만큼 늘어납니다.

`GEMINI_MODEL`은 **"이것부터 써라"**는 뜻입니다(고정이 아닙니다). 그 모델이 막히면 나머지로 넘어갑니다.
평소에는 **비워 두는 것을 권장**합니다 — 구글이 모델을 교체해도 알아서 따라갑니다.

### 💰 유료 — Claude (품질 최상)

1. `https://console.anthropic.com` → **Billing** → 충전 (최소 $5)
2. **API Keys** → **Create Key** → 키 복사
3. Render → Environment → `ANTHROPIC_API_KEY` → Save

초안 1건당 약 $0.1~0.2. $5로 25~50건. "모델을 Sonnet으로 바꿔줘"라고 하시면 60% 절감됩니다.

> **둘 다 넣으면 Claude를 씁니다.** 무료로 쓰시려면 `ANTHROPIC_API_KEY`를 비우거나 삭제하세요.

## F. 자주 겪는 문제

| 증상 | 원인·해결 |
|---|---|
| 사이트가 30~50초 안 열림 | UptimeRobot이 5분마다 깨워두므로 이제 발생하지 않음. 계속 느리면 UptimeRobot 모니터가 Pause 됐는지 확인 |
| AI 생성이 "설정되지 않았습니다" | Claude 크레딧/키 문제 (D 참고) |
| AI 생성이 "인증에 실패했습니다" | Render의 `ANTHROPIC_API_KEY` 값이 틀렸거나 폐기된 키입니다. 새 키를 발급해 다시 넣으세요 (D 참고) |
| AI 생성이 "크레딧이 없습니다" | 키는 맞고 잔액이 0입니다. https://console.anthropic.com/settings/billing 에서 충전하거나, **📋 AI 프롬프트 복사**로 각자 claude.ai에서 쓰면 됩니다 |
| 초안이 몇 글자짜리로 나옴 | 무료 엔진이 '생각'만 하다 끝난 경우입니다. 블로그봇이 자동으로 다시 요청하고, 그래도 안 나오면 저장하지 않고 알려줍니다 (쓰레기 초안이 남지 않게) |
| 무료 엔진이 "지금 많이 붐빕니다" | 무료 모델이 몰리는 시간대입니다. 블로그봇이 3초 뒤 재시도하고 다른 모델로도 바꿔 보지만, 전부 대기 중이면 이 안내가 나옵니다. 몇 분 뒤 다시 누르거나 **📋 AI 프롬프트 복사**를 쓰세요 |
| 무료 엔진이 `no longer available to new users` | 구글이 그 모델을 신규 사용자에게 막은 것입니다. 블로그봇이 쓸 수 있는 모델을 자동으로 고르므로 최신 버전만 올리면 해결됩니다. Render에 `GEMINI_MODEL`을 직접 넣어 두셨다면 **그 변수를 삭제**하세요 (자동 선택을 막습니다) |
| 초안을 못 만들겠다고 함 | 키워드를 넣고 **✍️ 직접 쓰기**를 누르면 됩니다. AI 크레딧이 없어도 작동합니다 |
| 초안이 안 보임 | 계정마다 초안이 따로 보관됩니다. 견본은 "견본 초안 가져오기" 버튼으로 |
| 원장이 못 들어간다고 함 | 승인을 안 하셨을 수 있습니다. 회원 관리 탭에서 승인 |

## H. 등급 정책

| 등급 | 권한 |
|---|---|
| **관리자** (우진) | 초안 생성 무제한, 회원 승인·등급 변경, 전부 사용 |
| **원장 (1단계)** | 승인 후 레퍼런스 열람 + 초안 작성. AI 생성 **월 10회** |
| **승인 대기** | 가입만 하고 승인 전 — 아무것도 못 봄 |

원장별 월 한도는 **회원 관리** 탭에서 조정할 수 있습니다.

### 누가 몇 개 썼는지 보기 (관리자 전용)

**회원 관리** 탭에서 각 원장 옆에 **📝 N개 · 마지막 작성일**이 표시됩니다. 초안을 하나씩 열어보지 않아도
누가 얼마나 쓰고 있는지 한눈에 보입니다. **초안 작성** 탭의 회원 선택 칸에도 `(N개)`가 함께 나옵니다.
원장 본인에게는 이 정보가 보이지 않습니다.

### 초안은 누가 볼 수 있나

초안은 **계정별로 따로** 보관됩니다. 서버가 재시작돼도 사라지지 않습니다.

| 누가 | 자기 초안 | 다른 원장의 초안 |
|---|---|---|
| 원장 A | ✏️ 쓰기·수정·삭제 | ❌ **볼 수 없음** |
| 원장 B | ✏️ 쓰기·수정·삭제 | ❌ **볼 수 없음** |
| 관리자(우진) | ✏️ 쓰기·수정·삭제 | 👀 **열람 가능** (수정·삭제는 불가) |

**원장끼리는 서로의 글을 볼 수 없습니다.** 누가 어떤 글을 썼는지는 관리자만 확인할 수 있습니다.

#### 관리자가 원장 글을 보는 법
**초안 작성** 탭 → 왼쪽 위 **회원 선택 칸**에서 원장 이메일 선택 → 그 원장의 초안 목록이 뜹니다.
열람 중에는 주황색 안내줄이 뜨고 저장·삭제·AI 생성 버튼이 사라집니다. **본문 복사**는 되므로 피드백용으로 가져올 수 있습니다.
내 초안으로 돌아오려면 같은 칸에서 **📝 내 초안**을 고르세요.

같은 제목으로 써도 서로 덮어쓰지 않습니다. "📥 견본 초안 가져오기"를 누르면 견본이 **내 계정으로 복사**되므로, 내가 고쳐도 다른 원장에게는 영향이 없습니다.

> 권한 규칙은 [permissions.mjs](permissions.mjs) 한 곳에 모여 있고, `node --test` 로 검증합니다.
